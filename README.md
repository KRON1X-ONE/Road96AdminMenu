# Road 96 Admin Menu

Внутриигровое админ-меню (мод) для игры **Road 96**, выполненное строго в аутентичном визуальном стиле игры. Добавляет новую вкладку **«АДМИН»** в стандартное меню паузы (`ESC`), а также функции свободного полета и прохождения сквозь стены.

---

## ⚡ Возможности

1. **Интеграция в интерфейс игры:**
   - Открывается по нажатию клавиши `ESC` среди родных вкладок игры («Прогресс», «Собранные предметы», «Параметры», **«Админ»**).
   - Все кнопки, цветовая палитра и шрифты полностью повторяют стилистику Road 96.
2. **Накрутка денег:**
   - Поле для ввода любой произвольной суммы с кнопкой `+ ВЫДАТЬ`.
   - Быстрые кнопки мгновенного добавления: `+10$`, `+50$`, `+100$`, `+500$`.
   - Отображение текущего баланса в реальном времени.
3. **Накрутка энергии (выносливости):**
   - Точное изменение по делениям шкалы: `+1 ЭНЕРГИЯ` (+1 полоска), `-1 ЭНЕРГИЯ` (-1 полоска).
   - Кнопка `МАКСИМУМ ЭНЕРГИИ` — мгновенно восстанавливает шкалу до предела.
   - Кнопка `МИНИМУМ ЭНЕРГИИ` — оставляет 1 деление (критический уровень сил, без мгновенного падения в обморок).
   - Отображение текущих делений (например, `7 / 7`, `4 / 7`).
4. **Режимы перемещения (читы):**
   - **NoClip [V]** — свободный полёт сквозь любые препятствия, стены и заборы.
     - Полёт направлен строго туда, куда смотрит камера в 3D (смотрим вверх и жмем `W` — летим вверх в небо). Без лишних биндов на пробел/контрол.
     - При выключении персонаж остаётся ровно в том месте, где был выключен NoClip (без откатов назад).
   - **FreeCam [F2]** — свободная летающая камера для осмотра локаций и скриншотов. Тело персонажа остаётся на месте, пока вы летаете камерой.
   - **Ускорение полёта:** зажмите `Shift` для быстрого перемещения (25 м/с вместо 10 м/с).
   - Переключать можно как горячими клавишами (`F2` и `V`), так и кнопками внутри вкладки «Админ».

## 🛠 Требования для работы мода

Для работы мода на вашем компьютере должны быть установлены:
1. **.NET 6.0 Runtime (x64)**:
   - Скачать [.NET 6.0 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/6.0) (Windows x64).
2. **MelonLoader (версия v0.6.x или v0.7.x для Il2Cpp / .NET 6)**:
   - Скачать установщик с официального сайта: [melonwiki.xyz](https://melonwiki.xyz/) или репозитория [MelonLoader на GitHub](https://github.com/LavaGang/MelonLoader).
   - В установщике выберите файл `Road 96.exe` и нажмите **Install**.

---

## 📦 Установка мода

1. Убедитесь, что вы установили MelonLoader в папку с игрой.
2. Скопируйте папку **`Mods`** из этого архива/папки прямо в корневую директорию игры:
   ```text
   <Папка с игрой Road 96>\Mods\Road96AdminMenu.dll
   ```
   *(Например: `C:\Program Files (x86)\Steam\steamapps\common\Road 96\Mods\Road96AdminMenu.dll`)*
3. Запустите игру. При первом запуске MelonLoader подготовит сборки, после чего мод автоматически загрузится.

## 🎮 Управление

| Клавиша | Действие |
| :--- | :--- |
| **ESC** | Открыть меню игры (вкладка **«АДМИН»** будет справа вверху) |
| **V** | Включить / выключить **NoClip** (полет сквозь стены по взгляду камеры) |
| **F2** | Включить / выключить **FreeCam** (свободная камера) |
| **W / A / S / D** | Полёт вперед/назад и стрейф влево/вправо в режимах NoClip и FreeCam |
| **Shift** | Ускорение полёта |

> **Примечание:** Горячие клавиши `V` и `F2` работают только во время геймплея и автоматически блокируются, когда открыто меню паузы, чтобы исключить случайные срабатывания при вводе текста или цифр.
